## Interfaz de Usuario – SEAE
Responsable: Gerson Ramirez

### Descripción
Se desarrolló la interfaz gráfica del sistema SEAE para permitir la interacción del usuario con los métodos económicos:

- Valor Presente Neto (VPN)
- Costo Anual Equivalente (CAE)
- Tasa Interna de Retorno (TIR)

### Funcionalidades de la interfaz
✔ Selección del método económico  
✔ Generación dinámica de alternativas  
✔ Captura de flujos de caja  
✔ Validación visual de errores  
✔ Visualización de resultados  
✔ Gráficos comparativos con Chart.js  
✔ Identificación automática de la mejor alternativa  

### Tecnologías utilizadas
- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES Modules
- Chart.js

### Rol dentro del proyecto
La interfaz conecta todos los módulos matemáticos desarrollados por el equipo y permite su uso mediante una aplicación web interactiva.
